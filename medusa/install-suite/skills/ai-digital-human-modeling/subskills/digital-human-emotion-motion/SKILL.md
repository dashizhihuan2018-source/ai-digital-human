# 数字人动作与表情

先回读认可的网格、骨架、手部母本和站姿，核对实际动作入口、目标观看尺寸和循环需求。标明会改的骨姿、形态键和剪辑，记录保留的纹理、蒙皮、绑定矩阵和旧动作名。改母本或骨骼时，先走 [骨骼与蒙皮](../digital-human-rigging/SKILL.md)。

1. 列出常态、单次动作、短表情的触发来源、循环、可打断条件和退回状态。定好起势、峰值、收势，再做视线、手指及头发、衣袖与裙摆的跟随。动作名沿用宿主约定。
2. 处理喜怒哀乐时，按 [四种情绪的表演指引](references/emotion-performance.md) 只读对应段。检查关键帧与连续播放，衣发接触、指节、甲面、眉眼权重和接地按 [绑定与运行](references/rig-and-runtime.md) 取证。
3. 导出后以同一宿主入口确认点播、自动轮换、会话抢占、可见性、减少动态效果和回到当前有效状态。固定探针时钟和真实前台分别验收。说话姿态、随音量开口、逐音节同步各自验证。
4. 交付可编辑源、独立命名的片段、运行清单与首尾证据。需要交互网页、录屏或发布时用 [导出与展示](../digital-human-delivery/SKILL.md)。私人助理的声线、身份和服务写入走 [私人助理角色](../private-assistant-character/SKILL.md)。
