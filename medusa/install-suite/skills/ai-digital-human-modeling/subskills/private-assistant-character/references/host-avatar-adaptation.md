# 桌宠资源适配

## 选择运行格式

- 实时 3D 适合动态换镜头、动作和表情。按宿主协议验证真正的三维首帧、加载失败与回切，读回贴图、蒙皮、形态键、实际片段和构图。
- 透明预渲染适合固定半身或全身构图，或表现需保留离线渲染的角色。从可编辑三维源输出透明 RGBA 待机与状态序列。核查帧数、帧率、透明边缘、锚点、边距和衔接。菲菲旧资源使用半身及全身分别 12 fps，宿主当前规范优先。
- 输入特殊格式时保留原始输入、转换工具和中间件。逐项标注保留、重建或缺失的轴向、尺度、纹理、网格、骨骼和表情。重复打包前查旧角色压缩或嵌入资源的真实来源。

## 宿主入口

回归桌宠拖动、双击对话、显隐、尺寸和减少动态效果。把会话状态映射到可用剪辑或帧段。使用 PCM 能量时核验采样窗口、出声时间、阈值和播完复位。打断、隐藏、换角色后清理旧状态。将 [动作编排与运行验收](../../digital-human-emotion-motion/SKILL.md) 的证据和原生声线路由分开记录。
