# 声源、试听与切换

1. 保留原件并记录本地路径、哈希、作品与版本、来源及用途、取样时码、台词和处理过程。分别辨识传播载体和实际音轨。官方采访节目内有剧中插段时，可标为剧中对白并保留节目出处。用实际音轨核对说话人、配乐、音效与同场他人。标题、画面和 ASR 提供线索。来源不足时标待核，采访语音、二创配音和合成声单独标明。
2. 从可用素材截取干净的单人连续语音，按需处理底噪或响度。优先通过换区间解决伴奏、混响和异说话人，复听处理伪影。保留实际参考文本、原截取、处理后音频和生成试听的对应关系。
3. 复用可用的本机 TTS 与 worker。记录模型与可核实的版本、依赖、参考哈希、参数、后处理及输出校验值。用同一句对照，另验开场、回复、问句和较长句。技术检查包括解码、采样率、声道、时长、峰值和转写。本人听感、选择及日期单列，保留已确认的试听文件。

沿用独立声线 ID 和设置。回读保存值与生效值，覆盖服务重启、未知选项、参考文件缺失及恢复。运行回退保留用户选择，处理中一句沿用开始时的声线。回归开场、回复、桌宠播报、打断与静音，确认专用朗读是否共用声线路由。隔离测试可真实本机合成并截取播放队列证据。真人麦克风、实际扬声器和用户试听各自记账。

原动画对白来自转载时，来源表分别登记原作、转载载体和实际截段。用片内镜头、字幕及前后说话人或解说切点定位。演员访谈可用来核对演员归属。背景声确实影响清楚度且无法换段时，可用本机分离器，保留处理前后对照。参考音频和对应文本视为一组，分别测试缺任一文件的降级。单样本声纹分数可帮助区分候选，听感仍由本人试听记录。
