# 数字人验收

- 视觉。原照片同姿态、同镜头和同裁切对比原本可见的五官、发量、轮廓和材质。原生发丝检查发际线、分缝、侧背连续性和近景。生成补视图只能验证设计自洽。
- 网格。读回边界、退化面、实际求值法线、活动 UV 和归一化蒙皮。局部修改时对比冻结区。用前肩、侧肩、抬臂或屈指等本轮动作检查变形。
- 输出。从单独空场景读回 FBX 或 GLB 的单位、轴向、纹理、蒙皮、形态键和片段时长。在目标 App 或浏览器实际加载同一文件。
- 播放。检查起势、峰值、收势、接地、衣发和复位。区分动捕、表演姿态、按音量开口和逐音节口型。录屏需对应同版实模。
- 证据。记录本轮候选、失败反例、使用的真实文件和构建。工具检查、视觉验收、本人认可和生产发布独立记录。适用门未闭合时为 PARTIAL；关键身份或交付条件失败时为 NO-SHIP。
