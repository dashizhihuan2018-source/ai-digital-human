# 可编辑网格路线

## 参考与造型

同一角色的多张参考按输入合同记录比例、镜头、光线和姿态。原照约束可见脸部及发型。AI 补图提供待认可的设计，先校正三视图再建模。单张图片需要标注遮挡和未知区域，正侧背固定镜头验证整体结构。

可识别真人通常交付 FBX，虚构角色在 Web 或桌宠场景通常交付 GLB。实际用户格式与宿主优先。交付中保留可编辑 Blender 源，原生曲线、布衣与控制器在源工程按需要保留。

## 虚构角色的初始形状

如输入的正、左、背视图已统一比例、姿势和造型，可用 Hunyuan3D-2mv 建立初始形状。输入用 front、left、back 三张同尺度 RGBA PNG。记录模型版本、各输入及输出的哈希、随机种子和管线参数。实际运行及生成文件可用于复验。阶段产物是粗网格，后续在 Blender 完成清理、重拓扑、UV、材质、绑定与实际视觉检查。

## 局部修补

先记录问题区域边界以及相邻受保护区域。补片和已认可网格共享接口，新增顶点从对应旧面传递和归一化权重。分别检查点位、实际剖分、UV 和着色。检查原恶化原因及修补处的连续姿势，提交轻量局部候选、边界对照、回退点和未覆盖项。
