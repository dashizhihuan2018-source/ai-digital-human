# 许可证、主体授权与隐私

公开仓库不等于自由使用。许可证审计必须按层完成，并与主体授权、输出用途和部署位置同时判定。任一必要层未知或用途冲突即 `NO-SHIP`。

公开照片、公开视频或名人素材不是训练授权。没有可审计主体授权时，只能使用合成或不可识别 fixture，或使用上游官方 demo 且其数据许可与主体同意范围均已核验；“能下载”“论文附带”或“仓库公开”都不能替代主体同意。

## 六层审计

1. 代码许可证：仓库根许可证、附加声明、修改/署名/分发义务和商业限制。
2. 模型权重许可证：checkpoint、预训练 tracker、分割/音频模型可能与代码不同。
3. 数据集许可证：下载资格、研究/商业范围、再分发、衍生物和主体同意。
4. 人体先验许可证：FLAME、SMPL/SMPL-X、MANO、VPoser 等分别登记版本和条款；[SMPL-X 官方页](https://smpl-x.is.tue.mpg.de/)要求注册并接受相应许可，[FLAME 官方页](https://flame.is.tue.mpg.de/)也有独立模型许可。
5. 主体授权：照片、视频、录音、声纹、动作、身份相似模型的训练、内部展示、公开展示、商用、保存期与撤回方式。
6. 输出用途：BLEND/GLB/Gaussian/checkpoint/视频/Web 服务是否分发，是否允许第三方再训练或下载。

依赖、submodule、CUDA rasterizer、字体、HDRI、服装纹理与运行时也进入 manifest。代码许可证不能替代模型权重许可证，数据集条款不能替代主体授权。

## 隐私分级

- 高敏：原始照片/视频/录音、声纹、身份 embedding、FLAME/SMPL-X 跟踪参数、可逆贴图、checkpoint、带人像的验证帧。
- 项目敏感：受控存储位置、访问名单、加密/删除记录、用途授权和内部版本 manifest。
- 可入 Skill：公开来源 URL/固定提交/许可证元数据、不含身份信息的规则、匿名计数和通用失败模式。

仓库策略是：不复制身份素材、不记录录音内容，不提交照片、视频、录音、声纹、跟踪参数、checkpoint，不写绝对本机路径，不把哈希当匿名化。报告可记录“音频包字节一致”“完整解码”等结论，不转写发言、不保存声纹特征。

## Apple Silicon / CUDA 外移

Apple Silicon 可保留本地预处理和 QA；CUDA/NVIDIA 训练只有在授权计算环境具备主体同意、传输加密、访问控制、存储地区/期限和删除证明后才能使用。不得自动上传。第三方 notebook、在线 demo、对象存储或临时 GPU 主机默认不获准接收身份素材。
