# 实模录屏与网站交付

适用于将已完成的 Blender 数字人或原生桌宠做成产品演示、作品网站和技能案例。“真实形象”指项目实际运行的角色网格和材质，包括冠饰、五官、服装和经确认的手部等关键特征。

## 同源角色与动作

1. 从项目交接定位经认可的角色母本、最新实装或候选构建。记录可编辑源文件、导出 FBX/GLB、实际加载的资源或 runtime bundle 的 SHA-256。以实际读取到的构建号、资源和动作名识别运行版本。构建并行时，选定同一组证据锁定全套网站媒体。单独保存技术验收与用户认可状态。
2. 确认动作标签、实际剪辑名、触发入口和设计预期。全身视角观察动作轮廓、脚底与衣发跟随，近景观察五官、手腕、手指和饰品。重点留出收势、闭眼、手指靠近衣物等容易看不清的位置。首页和封面从同源实模截取静帧，按手机和桌面分别确认脸、手势和画面裁切。
3. 分别标明证据来源。正常使用入口录得的是产品操作实录。用同版资源打开独立原生宿主并以实际时间播放，可标为原生实模录屏，同时注明录制路径。定步推进引擎或 Blender 逐帧导出可用于诊断或实模动作渲染。用骨骼或原创图形转译轨道时，标为动作分析。

## 实时录制

使用专用演示窗口。macOS 桌宠可取独立 App 窗口或原生 WKWebView 的单窗口画面。按用户要展示的操作，使用产品实际菜单或对应的播放接口触发。确认窗口可见，等待模型和画面就绪，再录一小段待机、完整动作、回到待机。每个动作都保留独立原始录屏。记录触发方式、动作名、实际用时和结束状态。若窗口后台节流导致播放停滞，恢复前台后复录并保留失败记录。

固定画幅、镜头和光照，先检查最大幅度动作的冠饰、手臂或裙摆是否出框。限定到目标窗口，展示动作的静音录屏不采集系统音频或麦克风；如任务需要语音，单独核对使用范围与音轨。逐个检查录屏与抽取静帧，清除账号、通知、会话、家庭布局、未授权音轨及其他非展示信息。利用 `ffprobe` 核对编码、像素尺寸、实际时长和音轨，完整解码并目视检查动作开始、峰值和结束。

## 网页同步与发布

- 让每个动作选项对应同版录屏、同一段视频截图、动作说明和实际时长。播放器可播放、暂停和跳转，按比例显示，在窄屏保留全身；验收键盘切换、媒体错误提示、下载或直达链接。首页的实模静帧可以另选同版角度，素材清单注明来源。
- 留存“角色及构建 → 剪辑与触发 → 原始录屏和截图 → 网页媒体及哈希”的对应表。网站和下载包只承载此次范围内的媒体和方法；可编辑工程、受限原始贴图、声线参考和运行资源按项目要求留档。
- 第三方角色造型、网格、贴图、配乐和声音分别核对许可证或公开展示许可。能从模型站下载、能在本机展示和能公开分发模型属于不同范围。确认是否允许项目宣传页展示截图和录屏后，再按已有站点发布流程操作。等待权利范围核实时，使用完整的本机网站预览审看实际素材；公网版本记录当前实际内容。具体审查见 [许可证、主体授权与隐私](licensing-and-privacy.md)。
- 已发布时从匿名客户端复验入口、媒体实际加载和播放、来源声明及线上构建。复用本地截图或浏览器测试时，明确其测的是本地构建。交接文件记录网页入口、角色构建、媒体清单、验证过的浏览器及待确认事项。
