# 私人助理角色

制作私人助理时按用户指定范围选做**声线、人设、动作**三项。外观是动作制作的资产基线，也可单独交付。宿主已有的外观、声线、人设选择器仍按实际接口分别验收。沿用现有选择器与服务接口，先核实角色名和唤醒词的归属，以及人设是否按当前角色或服务能力显示。分别核对显示条件、实际生效值和保存值。

1. 在宿主项目找到当前发布回执、源码、运行资源及接口。如宿主提供 `AGENTS.md` 或发布说明，读取当前接入规则。
2. 在独立目录记录角色名、所选轨、宿主父版本、原始输入和授权用途。输入足够的轨直接进行。遇到不可读模型、声源用途不明或角色资料仅有二创时，把影响限定在该轨，继续其余工作。未选轨沿用现有选择和默认行为。
3. 各轨交付最小可接入产物、来源和验证记录。统一候选以同一父版合并。设置栏、桌宠入口、身份路由或语音服务有重叠改动时，核对实际父版本，合入增量并复查其他轨。作者工程、原件、转换母本和运行资产分开保存。

## 按轨读取

- **外观**。输入模型、贴图和参考视图。按宿主能力制作实时 3D 或透明预渲染桌宠。读 [外观与运行格式](references/appearance.md)。
- **声线**。输入可用声源、用途和试读方向。核实原角色对白、采访、宣传剪辑、二创或合成来源。读 [声源、试听与切换](references/voice.md)。
- **人设**。输入角色参考、希望保留的性格和关系、原创改编范围。交付独立选项、原创提示词和对话样例。读 [人设与对话行为](references/persona.md)。
- **动作**。依据已认可的母本制作片段和表情，核对动作优先级、轮换、回待机和真实原生表现。读 [动作与交互状态](references/motion.md)。
- **接入**。以独立 App 标识、配置及回环服务验证原生「我的 → 私人助理」、桌宠、聊天和通话的相关入口。读 [隔离、回归与接入](references/integration.md)。需要核查依据时读 [项目实证](references/case-evidence.md)。

## 完成条件

验证选项独立、原默认值、旧偏好、资源缺失和服务降级。设备和外部服务使用只读查询或模拟写入。交接分别记录工具检查、原生端到端、本人试听或观察、正式发布，并列出待验证项。正式接入由宿主有权限的总控在当前基线上复验并执行。按本次授权在本机处理素材，原件和衍生文件留在项目工作目录。下载、上传、对外发布及正式环境变更分别核实授权。
