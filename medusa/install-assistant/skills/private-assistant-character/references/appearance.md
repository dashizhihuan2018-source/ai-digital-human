# 外观、表情与动作

## 选择交付形态

- **实时 3D**适合可转向、换动作和实时驱动表情的角色。先用宿主已有路径。AppKit 或 SwiftUI 承载的桌宠，可以使用 WKWebView 中的三维引擎或宿主支持的其他渲染路径。分别验实际模型首帧、加载状态和用户所见画面。采用 glTF/GLB 时，回读实际交付文件的纹理绑定、动画通道、蒙皮、面部形变和边界，并在宿主内核对。
- **预渲染桌宠**适合固定半身或全身构图，或原材质、毛发和布料难以在宿主渲染器保真时。保留可编辑三维源，按宿主协议输出透明 RGBA 状态帧和动作序列。检查各构图的待机图、动作清单、帧率、帧数、透明通道、边距、锚点及待机衔接。菲菲历史资源采用 12 fps 和半身／全身独立目录。新角色规格以当前宿主为准。
- 检查输入模型的单位、轴向、层级、骨骼、权重、表情键和外部贴图。特殊格式保留转换器版本、命令、日志及可编辑中间件。对照原文件及角色参考，逐项记录成功保留、重新补建和未恢复的资产。

## 动作与表情

锁定用户已认可的脸、眼、发型、服装和饰品。查看实际网格变形的关键帧和原生尺寸。眼部检查眼神目标、眼睑闭合、眼球边缘及高光连续。张嘴检查唇齿和口腔。全身检查鞋底在构图内、着地连续及穿模。跳跃可记录求值后双鞋底离地高度和落地点，并结合观察。视觉不合格版本留作诊断，运行资产回到已认可版本。

复用待机、聆听、思考、说话和动作入口。按现有行为回归双击打开对话、拖动、显隐、尺寸和减少动态效果。说话可用本地合成播放队列的 PCM 能量和时间戳驱动多档开合。分别验证振幅同步、逐音素口型和真实扬声器时延。检查打断、播完、隐藏、切换角色后是否清除过期播放状态。资源不齐时走运行回退，并保留保存值。

导出后在空白场景重导运行 GLB，核对骨架、蒙皮、材质和变形，再用 macOS WebKit 或宿主对应运行器逐个发出动作命令。用原生菜单触发代表性动作和表情，抓取不同画面，区分全量动作命令通过与逐动作人工看图。多个角色共用渲染包时，重建前查清旧角色压缩或嵌入资产的来源，构建后实际切回旧角色验证首帧。
