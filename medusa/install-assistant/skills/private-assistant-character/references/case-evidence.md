# 美杜莎与菲菲案例

[美杜莎三维舞台与实模录屏](https://dashizhihuan2018-source.github.io/ai-digital-human/medusa/#experience)使用 macOS 全屋智能家居桌宠的同源模型。网站可点播七种完整动作，原生会话行为由 App 单独验收。

## 美杜莎

- **声线**。按片内镜头、字幕和说话人切点，在《斗破苍穹·三年之约》中确认彩鳞对白。把背景分离后的单人语音与对应文字配为参考，使用本机 TTS 合成新句。正式构建 240 有从回复触发到播放结束的回执。隔离验证覆盖参考缺失时的降级。真人麦克风唤醒及用户听感仍待单独验证。
- **人设**。将彩鳞的冷静、果断和护族担当转成原创现代私人助理对话，保留独立人设选项。显示身份、唤醒词、对话风格分别验证。隔离用例覆盖旧黄亦玫选项、未知值、服务重启、跨声线保留人设及家居请求分流。正式构建 240 回读了角色选择和文字回复的路由结果。
- **动作**。动作改版保留已认可的网格、索引、纹理、蒙皮权重和逆绑定矩阵，增加五种面部形变和十四个片段。三种常态包含待机、聆听和说话，七种轮换动作包含喜怒哀乐、沉思、打招呼和打瞌睡，四种短表情包含轻眨眼、浅笑、凝眉和忧思。全身与半身逐项检查。隔离 WebKit 验证了两轮洗牌、会话抢占、隐藏暂停和播完回待机。正式构建 248 观察到了原生自动轮换和全身／半身切换。说话姿态带口型曲线，真人音节同步仍待验证。
- **接入**。外观、声线、人设分别选择。隔离原生验证重开保存和切回菲菲。公开舞台使用独立的网页运行环境，可用同源 GLB 核对手势和构图。App 的自动轮换、会话抢占与声线播放以原生回读为准。

## 菲菲

- 采用半身和全身独立的预渲染资源。原生端分别验证四种会话状态和代表性动作，点播完成后回待机。回切三维角色时也检查实际首帧。
- 声线、人设及唤醒身份各自回读。来源记录区分节目载体与其中的剧中对白。试读覆盖本机合成与缺素材回退。黄亦玫人设依宿主当前选项的可用条件生效，恢复条件时需要回读已保存选择。

案例公开包提供制作方法。实际复现需准备对应使用场景允许使用的模型、参考声源和宿主。
