# 人设与对话行为

先做短角色卡，注明用户确认的设定、原作事实及出处、待核资料和原创改编。以用户指定参考、官方正片或可核实一手资料为依据，按场次和说话人检查。采访、宣传片、同人解读和生成台词分别标注。保留影响交互的经历、关系和语气。

用原创提示词写称呼、语气、主动程度、自我介绍和边界，附原创场景样例。按话题少量选用样例，避免反复套话。用闲聊、首次认识、事实问答、用户纠正、打断及结束通话验证。未指定唤醒词或称呼变化时沿用宿主约定。

聊天与通话共用角色设定或明确各自入口。角色身份、唤醒词、人格、声线与外观的映射以当前宿主为准。菲菲早期唤醒身份随外观同步，黄亦玫人设曾在菲菲声线下生效。条件不满足时停用对应人设，恢复条件后读回明确选择。缺项与无效值走兼容默认，服务缺能力时继续既有对话。

人格只影响表达。设备、账号、交易和外发沿用宿主权限、确认、目标消歧、否定识别与执行回执。隔离验证其风格下的正常只读查询、含否定或歧义的控制请求以及确认前零写入。

若新角色扩展既有角色路由，优先复用旧设置键和 API 的兼容语义。身份展示、唤醒词和模型人设各自定义优先级，然后覆盖「随声线」、原人设和新人设的有效组合。对每个组合复验文字、通话开场和告别。提示词与权限夹具通过后，用实际目标模型抽样检查风格、无依据的细节和工具结果。按模型记录结论。
