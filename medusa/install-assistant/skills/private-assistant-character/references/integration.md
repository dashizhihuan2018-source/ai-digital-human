# 隔离、回归与接入

用可追溯的当前正式源码和资产建立候选。App 与服务各自回读实际已部署的父版及哈希，暂存差异单列。保留仍待合并的独立增量，共改文件按共同父版三方合并。隔离 Bundle ID、偏好域、语音服务目录、会话数据及回环端口。真实设备写入、交易和外发用夹具。需要真人收音或扬声器时，确认测试所用的候选入口，避免与正式麦克风争用。

- **原生操控**。从「我的 → 私人助理」实际选项入手，操作桌宠、聊天或通话。原生可访问性日志核对控件与选择；原生画面或探针确认真实首帧和动作；播放输出和引擎回执确认实际声线。
- **交叉选择**。每次改变外观、声线或人设的一项，回读其余选择器的保存值，核对预期的身份或能力联动。动作按当前外观和交互状态单独验证。切回原角色，重开 App 和服务，核对保存值和生效值。
- **旧配置**。测试新建与已有偏好，覆盖旧 ID、两端版本差异、无效值、缺资源和服务离线。设置卡结构有变化时，检查自定义次序、写回和可见性。构建 229 曾验证合并卡取代旧四卡中最靠前的位置并保留其余卡片的相对顺序。
- **端到端**。先用夹具验证入口、权限与故障，再按所选轨走原生资产、真实本机合成或无副作用语音查询。记录探针、离线合成、合成语音 ASR、真人实听及真实设备动作各自覆盖的范围。退出时只处理本轮候选进程和配置。

交接记录父版及源文件哈希、补丁根与试应用结果、每条轨产物及安装位置、资源来源与校验、候选路径与构建签名、证据、回退方式和待验项。App 和服务同时变化时列出一起接入的接口与资源。多套历史补丁按父版择一，核对实际合并结果。

正式接入由宿主项目维护者在当前基线上复验，依据项目现行安装入口。记录新进程的目标构建、原生入口、角色资源、音频输出及宿主原有服务的冷启动。按本次覆盖范围记录本人验收结论。

App 与语音服务同批变更时，交接附两侧候选和回退对应关系。隔离验收覆盖同一正向组合、只撤回一轨和整体恢复旧组合。正式验收同时留原生选择与资源就绪读数、文字路由结果、从播报准备到播放完成的记录。真实回放到输出可证明链路打通，声线听感和本人唤醒仍各自验收。
