# 哀

先按 [数字人情绪动作共用流程](../digital-human-emotion-motion/SKILL.md) 核对母本、原待机和交付入口。

- 视线先落，胸口和肩颈随后松沉，动作在停顿后徐缓复位。需要胸前收手时，先确定手势朝向和停的位置。
- 一手胸前悬停可留出指尖、袖口到衣襟的净空。另一手可贴近自然下垂，回收两个腕点的小节奏。
- 眼睑、睫毛、眉和嘴角做独立曲线。闭眼时核验脸与睫毛的权重同步。回势可先恢复视线，再收回双手和躯干。
- 输出 `EmotionSorrow` 或项目约定的动作名。逐帧检查收手和回势中手、袖与胸前饰件，成片提供全身和表情手势近景。
