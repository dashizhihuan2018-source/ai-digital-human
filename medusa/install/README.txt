数字人情绪动作 · Codex 技能包

在 macOS 解压整个 ZIP，然后打开 install.command。
如使用终端，在解压目录运行 bash install.command。

安装包内含 5 个 Codex 技能。运行后在 Codex 中输入
$digital-human-emotion-motion，也可以按需直接调用喜怒哀乐子技能。
已经打开的聊天若尚未显示技能，请新开一个 Codex 聊天。

安装只复制包内技能文件，默认位置为 ~/.codex/skills。
如设置了 CODEX_HOME 则沿用该目录。同名不同版本由安装程序保留并提示。
技能资料适用于 Blender → GLB → 原生桌宠的项目工作流。
